# 💰 Project_FL – Expense Splitting Web App (Flask)

Project_FL is a web-based expense splitting application inspired by apps like **Splitwise**.  
It allows users to create groups, add expenses, and track who owes whom.

This project is built using **Python (Flask)**, **MySQL**, and **HTML/CSS**.

---

## 🚀 Features

- User Registration & Login  
- Dashboard for tracking expenses  
- Add new expenses  
- Group-based expense sharing  
- Chat-style group UI  
- Secure authentication  
- Environment-based configuration  

---

## 🛠 Tech Stack

| Layer | Technology |
|------|-----------|
Backend | Python (Flask)
Database | MySQL
Frontend | HTML, CSS
Version Control | Git & GitHub
Environment | Virtualenv, .env variables
